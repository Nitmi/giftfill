# GiftFill · 礼卡快填

面向美区 Apple Gift Card 的 Chrome / Edge 扩展。多份常用资料、可选的本地加密银行卡库，以及停在付款信息页的访客快捷结账。当前版本 v0.2.0。

## 安装

要求 Chrome 116+ 或支持 Side Panel 的当前 Edge。

1. 运行 `npm ci` 和 `npm run build`，或解压已构建的发布包。
2. 打开 `chrome://extensions` 或 `edge://extensions`，开启开发者模式。
3. 选择“加载已解压的扩展程序”，选择 `.output/chrome-mv3`（发布包中为 `extension`）目录，确认该目录包含 `manifest.json`。
4. 固定 GiftFill 图标。点击图标打开侧边栏，创建一份资料并保存。
5. 安装/更新后刷新已打开的苹果页面，让填写器载入。

## 使用

1. 创建资料，保存金额、收发件姓名邮箱，以及联系与实际账单信息。
2. 可选：展开“付款卡库”，设置独立解锁口令，保存卡号和有效期，并给当前资料选择卡片。每次打开面板需解锁；CVV 不保存。
3. 选择资料后点击“快捷结账”。自动填写商品页、Add to Bag、核对购物袋、Check Out、Continue as Guest、展开银行卡表单并填写联系/账单/所选卡片。停在付款信息页，用户核对、输入 CVV 并手动继续。
4. 也可继续使用“填写此页”：仅填写当前商品页或银行卡结账页，不跳转。在结账页会自动展开信用卡表单。联系邮箱为空时使用发件邮箱。
5. 已有联系信息默认保留。需要切换到另一套完整资料时，可勾选“替换页面中已有的联系信息”。金额和账单国家始终按所选资料选择。页面已有不同银行卡时保留它并提示手动处理。
6. 快捷流程固定作用于启动时的标签页，面板须保持打开，可以停止。购物袋须只有一张电子礼品卡，数量、金额、To/From 必须与资料一致。出现未知跳转或验证、等待超时，自动停止；不会重试可能已经成功的点击。

资料可以留空；只填写资料中有值的字段。账单国家与商店地区分别配置，商店固定美区。支持原生下拉、国家自定义下拉、ZIP 对应的 City/State 选择；无法精确匹配的选项会提示手动处理。

美国电话可保存十位号码或带 +1 的号码；填写美区电话框时去掉 +1，并识别页面自动添加的括号与连字符。非美国账单地址尚未在官网逐国验证。

## 数据与权限

- 联系资料保存在 `chrome.storage.local`，属于本地明文存储；没有服务器、网络上报或云端同步。
- 导出备份是明文 JSON，包含邮箱、电话和地址；请自行妥善保存。导入采用新增副本，不覆盖已有资料。
- 内容脚本匹配美区礼品卡商品页、`/shop/bag`、Apple 访客入口 `/shop/signIn` 和 `/shop/checkout`。额外检查 HTTPS、精确主机和路径；没有 iframe 注入。受浏览器主机权限机制影响，苹果域名权限提示可能比路径描述更宽。
- 全部资料仅由扩展页面读取；每次点击仅把所选资料发送给目标标签页。
- 卡库单独以 AES-256-GCM 加密，随机盐和每次保存的新 IV；PBKDF2-SHA256 600,000 次派生不可导出的密钥。解锁口令和密钥不持久保存，卡库不进入资料备份。解锁仅在当前面板内有效，5 分钟闲置或关闭后锁定。
- 只有本次选中的卡号和有效期会交给 Apple 银行卡表单；CVV 不保存、不读取。不会读取 Chrome / Edge 已存卡库，可继续用浏览器原生填充。银行卡录入需用户在插件卡库完成。
- 不点击银行卡信息页的 Continue、最终购买按钮，也不处理登录、OTP、CAPTCHA 或支付验证。安全设计和适用边界见 `docs/security.md`。

## 开发与验证

```text
npm ci
npm run check
npm run test
npm run build
npm run zip
```

`npm run preview` 在 http://127.0.0.1:5173/preview/ 提供界面预览，预览数据仅保存在该本地页面的 localStorage。它不具备扩展的页面填写能力。

30 项测试覆盖原有填写回归，以及卡库加密、篡改/错误口令、锁定、卡片校验、购物袋核对、导航取消、重复点击防护、付款按钮边界。官网验证范围见 `docs/validation.md`。

目前已验证填写引擎和普通页面界面；Chrome / Edge 原生扩展安装、侧边栏与消息联动需在实际浏览器安装后验收。

## 工程结构

- `lib/profile.ts`：资料格式、校验、导入边界。
- `lib/fill.ts`：独立填写引擎与结果核对。
- `lib/assist.ts` / `lib/flow.ts`：明确允许的导航操作与跨页流程。
- `lib/vault.ts` / `ui/vault-panel.ts`：本地加密卡库与解锁面板。
- `entrypoints/apple.content.ts`：官网消息接收与操作互斥。
- `entrypoints/background.ts`：侧边栏与存储权限。
- `ui/`：侧边栏与资料管理共用界面。
- `tests/`：DOM 回归测试。

本项目独立实现；调研中的公开源码项目仅作为流程参考，未复制其源码。工程使用 WXT，项目本身采用 MIT 许可证。
