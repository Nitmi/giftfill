# GiftFill · 礼卡快填 v0.2.0

美区 Apple Gift Card 的 Chrome / Edge 扩展。

## 更新已有版本

1. 先导出联系资料备份。
2. 解压 `GiftFill-0.2.0.zip`。
3. 将新包中 `extension` 文件夹的全部内容复制到**原来已加载的 extension 文件夹**并覆盖，保留原目录路径。
4. 在 `chrome://extensions` 或 `edge://extensions` 点击 GiftFill 的“重新加载”。如浏览器提示新增 Apple 购物袋/访客入口权限，允许后继续。
5. 刷新已经打开的苹果网页。

这样保留原扩展 ID 与已有联系资料。不要卸载旧版再装，否则浏览器会删除扩展存储。

## 首次安装

1. 解压 ZIP，保留解压文件夹。
2. 打开扩展管理页，开启“开发者模式”，点击“加载已解压的扩展程序”。
3. 选择包内 **extension** 文件夹，它直接包含 `manifest.json`。
4. 固定扩展图标，点击打开侧边栏，再刷新苹果页面。

要求 Chrome 116+ 或支持 Side Panel 的当前 Edge。无需 Node.js。尚未发布到扩展商店。

## 新增功能怎么用

1. 编辑常用资料，补全收发件姓名邮箱、电话、订单联系邮箱与实际账单地址。快捷结账需要完整的 From / To；订单邮箱为空时自动使用发件邮箱。
2. 可选：展开 **付款卡库**，设置至少 12 字符的独立口令，录入卡片昵称、卡号和有效期。在“当前资料使用的卡片”中选择这张卡。它会记住资料与卡片的绑定。
3. 下次打开面板先解锁卡库，再选择资料，点击 **快捷结账**。
4. 插件填写商品页、加入购物袋、核对后 Check Out、Continue as Guest，自动展开信用卡表单，填写联系、账单与选中的卡片。
5. 流程停在付款信息页。核对金额、邮箱、电话、账单与卡片，自己输入 CVV，再手动继续和确认购买。

不用插件卡库也能使用快捷结账，到银行卡页后使用 Chrome/Edge 原生自动填充。插件不能直接读取浏览器已经保存的银行卡，需使用原生填充或自行在插件录入。

“填写此页”仍保留：商品页只填写，不加入购物袋；结账页自动展开信用卡表单并填写，不继续跳转。卡库锁定时填写联系资料，不填银行卡；解锁后可再点一次。

## 安全与中断

- 卡库 AES-256-GCM 加密，仅本地保存；口令、密钥不持久保存，没有云同步。5 分钟闲置或关闭面板后锁定。
- CVV 不保存、不读取，每次由你在苹果页面输入。卡库不会出现在普通 JSON 备份中；忘记口令无法恢复。
- 快捷流程只作用于启动时的标签页；保持面板打开，可以点击停止。
- 购物袋只能有一张电子礼品卡，数量为 1，金额和收发件信息必须与所选资料一致。否则停止，避免误结账或重复购买。
- 默认保留页面已有联系信息；需要整套替换时勾选替换选项。不同银行卡不会被自动覆盖。
- 遇到未知跳转、登录/支付验证或超时会停止；不反复点击 Add to Bag。银行卡页 Continue 和最终购买按钮均由你操作。
- 联系资料与 JSON 备份仍为明文，包含邮箱、电话和地址。详细设计与保护范围见 `SECURITY.md`。

## 排查

- **页面尚未连接**：更新扩展后刷新苹果页面，再试。
- **购物袋信息不一致**：核对数量、金额、From / To，移除额外商品或选择正确资料。
- **已保留**：已有内容与资料不同。联系字段可勾选替换；银行卡需先在页面清空卡号或自行核对。
- **卡库已锁定**：重新解锁，核对当前资料的绑定卡片，再点击“填写此页”。
- **超时 / 未找到**：处理网页提示、网络或额外验证后再开始。插件不会自动重试可能已成功的点击。

## 验证范围

类型检查、构建和 30 项自动测试通过。正式内容脚本已通过模拟扩展消息入口在真实 Apple 页面验证自动加入购物袋、Check Out、Continue as Guest、展开信用卡表单及填写合成联系/账单/测试卡号；CVV 保持为空，未继续购买。测试礼品卡已移除。

新版本的原生 Chrome/Edge 侧边栏跨页联动仍需安装后验收。Apple 风控、银行授权、支付完成、非美国账单、Apple Pay 和独立支付 iframe 未覆盖。见 `VALIDATION.md`。
