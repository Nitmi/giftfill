# GiftFill · 礼卡快填 v0.3.0

## 更新已有版本

1. 可先在「管理资料」中导出联系资料备份。
2. 解压 `GiftFill-0.3.0.zip`。
3. 将新包 `extension` 内全部文件覆盖到**原来已加载的扩展目录**，保留原目录路径。
4. 在 `chrome://extensions` 或 `edge://extensions` 点击 GiftFill 的「重新加载」。
5. 刷新已经打开的苹果网页。

保留原目录可以保留扩展 ID 与联系资料。不要先卸载旧版，否则浏览器会删除扩展存储。

新版已删除银行卡保存、解锁与自动填写。加载后会清理旧版加密卡库；联系资料继续保留。银行卡改由浏览器或密码管理器管理。

## 首次安装

1. 解压 ZIP，保留解压文件夹。
2. 打开扩展管理页，开启「开发者模式」，选择「加载已解压的扩展程序」。
3. 选择包内 **extension** 文件夹，它直接包含 `manifest.json`。
4. 固定 GiftFill 图标，点击打开侧边栏。

要求 Chrome 116+ 或支持 Side Panel 的当前 Edge。无需 Node.js，尚未发布到扩展商店。

## 日常只需一键

第一次创建资料，保存金额、完整的收发件姓名邮箱，以及实际联系与账单信息。订单联系邮箱留空会使用发件邮箱。「送给自己」可复制收件资料到发件资料。

选择一份资料，点击 **一键开始**。扩展记住选择，自动打开或使用当前窗口中的 Apple 购买标签页，填写商品并加入购物袋，核对后 Check Out、Continue as Guest，展开账单表单并填写联系与账单信息。运行时保持面板打开，可点击「停止」。

流程停在付款信息页。使用 Chrome / Edge 或密码管理器填写银行卡，核对金额、收发件邮箱、联系方式、账单与付款信息，自行继续和确认购买。

「管理资料」集中提供编辑、复制、增删、导入和导出；填写详情默认收起。

## 遇到停止提示

- **资料未完整**：会直接打开编辑页并标出缺失的收发件字段，补全后保存。
- **页面未连接**：更新后刷新苹果页面再试。
- **购物袋信息不一致**：检查是否只有一张电子礼品卡、数量为 1，金额与 From / To 是否符合所选资料。
- **字段未找到 / 校验失败**：展开结果详情，按苹果页面提示处理。
- **超时或额外验证**：处理网络、登录或验证提示后重新开始。扩展不会自动重试可能已成功的加入购物袋操作。

选择资料后，已有联系与账单字段按资料替换，空字段跳过。卡号、持卡人、有效期与 CVV 不读取、不填写。付款页 Continue 和最终购买始终由你操作。

联系资料与备份为明文，详细边界见 `SECURITY.md`。官网验证及原生浏览器验收范围见 `VALIDATION.md`。
