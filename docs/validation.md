localhost 预览验证了：资料切换后刷新仍保持选择；编辑保存返回主界面；编辑、复制和备份入口只在管理页；无资料时可进入管理页导入。用模拟旧版加密对象验证加载后移除旧卡库，联系资料完全保留。预览不使用正式扩展存储，示例资料不随发布包提供。

## 验证限制

正式内容脚本的官网适配已验证，跨页流程核心经自动测试验证。Codex 内置浏览器不能安装用户 Chrome / Edge 扩展，因而实际浏览器侧边栏、自动打开/复用标签页、runtime 消息和关闭面板取消联动仍需安装后验收。

浏览器/密码管理器原生银行卡填充、Apple Pay、登录账号流程、非美国账单逐国校验、独立支付 iframe、风控、银行授权及订单完成未覆盖。页面字段核对通过不保证最终支付通过。Apple 改版后无法确认的步骤会停止并提示。
